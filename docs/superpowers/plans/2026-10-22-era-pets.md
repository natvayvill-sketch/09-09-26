# Era Pets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a small pixel-art pet that walks along the bottom of every page. Each era page shows its own pet, other pages show the last era's pet, and a mini Living Portrait pet is the default.

**Architecture:** A new `src/pet/` folder, set up like `src/tracker/`. Pure, unit-tested modules handle the behaviour state machine, animation maths, the roster (which pet for which era) and storage. A thin DOM layer (`petView.ts`) runs the `requestAnimationFrame` loop. A `Pet.astro` component sits in `PageLayout` with `transition:persist`, so the same pet survives Astro `<ClientRouter />` page-turns. Pages pass their era through a `data-pet-era` attribute on `<main>`.

**Tech Stack:** Astro 7 (ClientRouter / View Transitions), TypeScript (strict, `verbatimModuleSyntax`), vitest, plain DOM + CSS. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-22-era-pets-design.md`

## Global Constraints

- No new npm dependencies.
- Type-only imports must use `import type` / inline `type` (the tsconfig sets `verbatimModuleSyntax`).
- `@types/node` is **not** installed. Code under `src/` must not import `node:*` with types (see Task 3 for the untyped workaround in one test).
- Sprite files: one PNG per animation at `public/pets/<pet-id>/<anim>.png`, a horizontal strip of 32×32 frames. Frame count = image width ÷ frame size.
- Animation names: `idle`, `walk`, `sit`, `sleep`, `notice`, `react`. `idle` and `walk` are required. Fallbacks: `walk`→`idle`, `sit`→`idle`, `sleep`→`sit`→`idle`, `notice`→`idle`, `react`→`idle`.
- Pet choice: current era's pet → remembered last era's pet → `living-portrait`.
- Last era is stored in `localStorage`. "Dismissed" is stored in `sessionStorage` (for the visit). Every storage access is wrapped so failures never throw.
- `prefers-reduced-motion: reduce` or a viewport narrower than 480 px → the pet is stationary in the bottom-right corner.
- Display scale: 3× on fine pointers, 2× on coarse (touch) pointers.
- The pet layer never blocks clicks. Only the pet itself has `pointer-events: auto`.
- Code style matches `src/tracker/`: double quotes, semicolons, 2-space indent, short doc comments.
- Run the tests with `npm test`, the type check with `npm run check`, and the build with `npm run build`. Baseline before Task 1: 53 tests pass, the check is clean.

## Review Focus

1. **The window shrinks while the pet is near the right edge.** The pet must stay fully on screen and never walk off. *(Task 1 test: "keeps the pet on the surface when the window shrinks")*
2. **A long frame gap** (tab regains focus, slow device). A walking pet must stop at its target, not overshoot past the edge. *(Task 1 test: "walk stops at its target even after a huge time gap")*
3. **A roster entry lists an animation file that was never drawn or was misnamed.** This must be caught by a test, not discovered as a broken pet on the live site. *(Task 3 test: "has a PNG on disk for every animation a pet lists")*
4. **Storage is blocked** (private browsing, site data disabled). The site and pet must still work, falling back to the default pet, with no exceptions. *(Task 4 tests: "returns null / false when storage throws")*
5. **Fast navigation** (era A → era B → back to A before B's art finishes loading). The pet must end up as A's pet, not swap to B late. *(Task 5 manual check 6, since this lives in the DOM layer)*

```ts
/** An animation strip a pet can have: one PNG per name in public/pets/<pet-id>/. */
export type AnimName = "idle" | "walk" | "sit" | "sleep" | "notice" | "react";

/** What the pet is doing: an animation name, or one half of a pet swap. */
export type PetMode = AnimName | "enter" | "exit";

/** A horizontal stretch the pet can stand on, as the range its centre may occupy (px). */
export interface Surface {
  minX: number;
  maxX: number;
}

/** Cursor position relative to the pet's centre. */
export interface CursorInput {
  /** Horizontal offset, px. Negative = cursor is left of the pet. */
  dx: number;
  /** Straight-line distance, px. */
  dist: number;
}

export interface PetInput {
  /** null when there's no cursor (touch screens, or it left the window). */
  cursor: CursorInput | null;
  /** The pet was clicked or tapped since the last step. */
  clicked: boolean;
  surface: Surface;
  /** Reduced motion or a very narrow screen: never walk. */
  stationary: boolean;
}

export interface PetState {
  mode: PetMode;
  /** Centre x, px. */
  x: number;
  /** 1 = facing right (as drawn), -1 = mirrored. */
  facing: 1 | -1;
  /** Where walk / notice is heading, px. */
  targetX: number;
  /** Time left in a timed mode (idle, sit, sleep, react, enter, exit), ms. */
  timerMs: number;
  /** Time spent in the current mode, ms. Drives the animation frame. */
  modeMs: number;
  /** How long the cursor has been within noticeRadius, ms. */
  nearMs: number;
  /** Clicks are ignored until this reaches 0, ms. */
  cooldownMs: number;
}

export interface BehaviorSettings {
  /** px per second. */
  walkSpeed: number;
  /** [min, max] ms; the actual duration is picked at random in this range. */
  idleMs: readonly [number, number];
  sitMs: readonly [number, number];
  sleepMs: readonly [number, number];
  /** Chance (0..1) that idle leads to sit instead of walk. */
  sitChance: number;
  /** Chance (0..1) that sit leads to sleep instead of idle. */
  sleepChance: number;
  /** px. */
  noticeRadius: number;
  /** Furthest the pet shuffles towards a nearby cursor, px. */
  shuffleStep: number;
  /** px per second. */
  shuffleSpeed: number;
  /** How long the cursor must stay near to wake a sleeping pet, ms. */
  wakeAfterMs: number;
  reactMs: number;
  clickCooldownMs: number;
  enterMs: number;
  exitMs: number;
}
```

Create `src/pet/behavior.ts`:

```ts
import type { BehaviorSettings, PetInput, PetMode, PetState, Surface } from "./types";

export const DEFAULT_SETTINGS: BehaviorSettings = {
  walkSpeed: 40,
  idleMs: [2000, 6000],
  sitMs: [5000, 12000],
  sleepMs: [20000, 45000],
  sitChance: 0.3,
  sleepChance: 0.4,
  noticeRadius: 120,
  shuffleStep: 24,
  shuffleSpeed: 25,
  wakeAfterMs: 1500,
  reactMs: 800,
  clickCooldownMs: 1200,
  enterMs: 500,
  exitMs: 400,
};

const clamp = (n: number, lo: number, hi: number): number =>
  n < lo ? lo : n > hi ? hi : n;
const between = ([lo, hi]: readonly [number, number], rng: () => number): number =>
  lo + (hi - lo) * rng();

function moveToward(x: number, target: number, maxStep: number): number {
  const d = target - x;
  return Math.abs(d) <= maxStep ? target : x + Math.sign(d) * maxStep;
}

function enterMode(s: PetState, mode: PetMode, timerMs = 0): PetState {
  return { ...s, mode, timerMs, modeMs: 0 };
}

function toIdle(s: PetState, rng: () => number, cfg: BehaviorSettings): PetState {
  return enterMode(s, "idle", between(cfg.idleMs, rng));
}

function startWalk(s: PetState, surface: Surface, rng: () => number): PetState {
  const targetX = surface.minX + (surface.maxX - surface.minX) * rng();
  return { ...enterMode(s, "walk"), targetX, facing: targetX < s.x ? -1 : 1 };
}

function notice(s: PetState, input: PetInput, cfg: BehaviorSettings): PetState {
  const dx = input.cursor ? input.cursor.dx : 0;
  const shuffle = input.stationary ? 0 : clamp(dx, -cfg.shuffleStep, cfg.shuffleStep);
  return {
    ...enterMode(s, "notice"),
    facing: dx < 0 ? -1 : 1,
    targetX: clamp(s.x + shuffle, input.surface.minX, input.surface.maxX),
  };
}

export function createPetState(x: number, cfg: BehaviorSettings = DEFAULT_SETTINGS): PetState {
  return {
    mode: "enter",
    x,
    facing: 1,
    targetX: x,
    timerMs: cfg.enterMs,
    modeMs: 0,
    nearMs: 0,
    cooldownMs: 0,
  };
}

/** Start hopping out so a different pet can hop in. */
export function requestSwap(s: PetState, cfg: BehaviorSettings = DEFAULT_SETTINGS): PetState {
  return s.mode === "exit" ? s : enterMode(s, "exit", cfg.exitMs);
}

/** Advance the pet by dtMs. Pure: all randomness comes from rng (0..1). */
export function step(
  prev: PetState,
  input: PetInput,
  dtMs: number,
  rng: () => number,
  cfg: BehaviorSettings = DEFAULT_SETTINGS,
): PetState {
  const { surface } = input;
  const near = input.cursor !== null && input.cursor.dist <= cfg.noticeRadius;
  const s: PetState = {
    ...prev,
    // The surface can shrink (window resize), so keep the pet on it.
    x: clamp(prev.x, surface.minX, surface.maxX),
    targetX: clamp(prev.targetX, surface.minX, surface.maxX),
    modeMs: prev.modeMs + dtMs,
    timerMs: prev.timerMs - dtMs,
    cooldownMs: Math.max(0, prev.cooldownMs - dtMs),
    nearMs: near ? prev.nearMs + dtMs : 0,
  };

  // Swapping pets runs to completion and ignores the visitor.
  if (s.mode === "exit") return s.timerMs <= 0 ? enterMode(s, "enter", cfg.enterMs) : s;
  if (s.mode === "enter") return s.timerMs <= 0 ? toIdle(s, rng, cfg) : s;

  if (input.clicked && s.cooldownMs === 0) {
    return { ...enterMode(s, "react", cfg.reactMs), cooldownMs: cfg.clickCooldownMs };
  }
  if (s.mode === "react") {
    if (s.timerMs > 0) return s;
    return near ? notice(s, input, cfg) : toIdle(s, rng, cfg);
  }

  // A sleeping pet only wakes if the cursor lingers.
  if (near && s.mode !== "notice" && (s.mode !== "sleep" || s.nearMs >= cfg.wakeAfterMs)) {
    return notice(s, input, cfg);
  }

  const px = (speed: number): number => (speed * dtMs) / 1000;
  switch (s.mode) {
    case "notice": {
      if (!near) return toIdle(s, rng, cfg);
      const facing = input.cursor!.dx < 0 ? -1 : 1;
      return { ...s, facing, x: moveToward(s.x, s.targetX, px(cfg.shuffleSpeed)) };
    }
    case "idle":
      if (s.timerMs > 0) return s;
      if (input.stationary || rng() < cfg.sitChance) {
        return enterMode(s, "sit", between(cfg.sitMs, rng));
      }
      return startWalk(s, surface, rng);
    case "walk": {
      const x = moveToward(s.x, s.targetX, px(cfg.walkSpeed));
      return x === s.targetX ? toIdle({ ...s, x }, rng, cfg) : { ...s, x };
    }
    case "sit":
      if (s.timerMs > 0) return s;
      if (input.stationary || rng() < cfg.sleepChance) {
        return enterMode(s, "sleep", between(cfg.sleepMs, rng));
      }
      return toIdle(s, rng, cfg);
    case "sleep":
      return s.timerMs > 0 ? s : toIdle(s, rng, cfg);
  }
}
```

```ts
import type { AnimName, BehaviorSettings, PetMode } from "./types";

/** How high the pet hops when swapping in or out, px. */
export const HOP_PX = 24;

/** What to show when a pet doesn't have a strip, tried in order. */
const FALLBACKS: Record<AnimName, readonly AnimName[]> = {
  idle: [],
  walk: ["idle"],
  sit: ["idle"],
  sleep: ["sit", "idle"],
  notice: ["idle"],
  react: ["idle"],
};

export function resolveAnim(available: readonly AnimName[], wanted: AnimName): AnimName {
  for (const name of [wanted, ...FALLBACKS[wanted]]) {
    if (available.includes(name)) return name;
  }
  return "idle";
}

export function animFor(mode: PetMode): AnimName {
  return mode === "enter" || mode === "exit" ? "react" : mode;
}

export function loops(mode: PetMode): boolean {
  return mode !== "react" && mode !== "enter" && mode !== "exit";
}

export function frameAt(modeMs: number, fps: number, frameCount: number, loop: boolean): number {
  if (frameCount <= 1) return 0;
  const frame = Math.floor((Math.max(0, modeMs) / 1000) * fps);
  return loop ? frame % frameCount : Math.min(frame, frameCount - 1);
}

/** Vertical offset (px, negative = up) and opacity for the enter/exit hop. */
export function hop(
  mode: PetMode,
  timerMs: number,
  cfg: Pick<BehaviorSettings, "enterMs" | "exitMs">,
): { y: number; opacity: number } {
  if (mode !== "enter" && mode !== "exit") return { y: 0, opacity: 1 };
  const total = mode === "enter" ? cfg.enterMs : cfg.exitMs;
  const t = Math.min(1, Math.max(0, 1 - timerMs / total));
  return {
    y: -Math.sin(Math.PI * t) * HOP_PX,
    opacity: mode === "enter" ? t : 1 - t,
  };
}
```

```js
import { mkdirSync, writeFileSync } from "node:fs";
import { deflateSync } from "node:zlib";

const S = 32;
const INK = [58, 47, 40]; // --color-ink

const PETS = {
  "living-portrait": [201, 150, 98],
  "placeholder-b": [47, 111, 106],

const crcTable = Array.from({ length: 256 }, (_, n) => {
  let c = n;
  for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
  return c >>> 0;
});

function crc32(buf) {
  let c = 0xffffffff;
  for (const b of buf) c = crcTable[(c ^ b) & 0xff] ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
}

function chunk(type, data) {
  const len = Buffer.alloc(4);
  len.writeUInt32BE(data.length);
  const body = Buffer.concat([Buffer.from(type, "ascii"), data]);
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(body));
  return Buffer.concat([len, body, crc]);
}

function encodePng(width, height, rgba) {
  const stride = width * 4;
  const raw = Buffer.alloc((stride + 1) * height); // each row starts with filter byte 0
  for (let y = 0; y < height; y++) {
    rgba.copy(raw, y * (stride + 1) + 1, y * stride, (y + 1) * stride);
  }
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(width, 0);
  ihdr.writeUInt32BE(height, 4);
  ihdr[8] = 8; // bit depth
  ihdr[9] = 6; // RGBA
  return Buffer.concat([
    Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]),
    chunk("IHDR", ihdr),
    chunk("IDAT", deflateSync(raw)),
    chunk("IEND", Buffer.alloc(0)),
  ]);
}

/** Renders frameCount 32×32 frames side by side. drawFrame(put, f) draws frame f. */
function strip(frameCount, drawFrame) {
  const width = S * frameCount;
  const rgba = Buffer.alloc(width * S * 4);
  for (let f = 0; f < frameCount; f++) {
    const put = (x, y, [r, g, b]) => {
      if (x < 0 || y < 0 || x >= S || y >= S) return;
      const i = (y * width + f * S + x) * 4;
      rgba[i] = r;
      rgba[i + 1] = g;
      rgba[i + 2] = b;
      rgba[i + 3] = 255;
    };
    drawFrame(put, f);
  }
  return encodePng(width, S, rgba);
}

function ellipse(put, cx, cy, rx, ry, rgb) {
  for (let y = Math.floor(cy - ry); y <= Math.ceil(cy + ry); y++) {
    for (let x = Math.floor(cx - rx); x <= Math.ceil(cx + rx); x++) {
      if (((x - cx) / rx) ** 2 + ((y - cy) / ry) ** 2 <= 1) put(x, y, rgb);
    }
  }
}

function rect(put, x0, y0, w, h, rgb) {
  for (let y = y0; y < y0 + h; y++) for (let x = x0; x < x0 + w; x++) put(x, y, rgb);
}

/** A round blob creature facing right. feet: [leftDy, rightDy], or null to hide them. */
function blob(put, color, { dy = 0, squash = 0, eyes = "open", feet = [0, 0] } = {}) {
  const cy = 19 + dy + squash;
  if (feet) {
    rect(put, 10, 27 + dy + feet[0], 4, 3, INK);
    rect(put, 18, 27 + dy + feet[1], 4, 3, INK);
  }
  ellipse(put, 16, cy, 11, 10 - squash, INK);
  ellipse(put, 16, cy, 10, 9 - squash, color);
  const ey = cy - 2;
  if (eyes === "closed") {
    rect(put, 12, ey + 1, 3, 1, INK);
    rect(put, 19, ey + 1, 3, 1, INK);
  } else if (eyes === "wide") {
    rect(put, 12, ey - 1, 3, 3, INK);
    rect(put, 19, ey - 1, 3, 3, INK);
  } else {
    rect(put, 13, ey, 2, 2, INK);
    rect(put, 20, ey, 2, 2, INK);
  }
}

const ANIMS = {
  idle: [2, (put, f, c) => blob(put, c, { dy: f })],

};
```

```ts
export interface StorageLike {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
  removeItem(key: string): void;
}

type GetStore = () => StorageLike;

const LAST_ERA_KEY = "pet:last-era";
const HIDDEN_KEY = "pet:hidden";

// Merely touching window.localStorage can throw (blocked site data), so the
// stores are fetched lazily, inside the try.
const local: GetStore = () => window.localStorage;
const session: GetStore = () => window.sessionStorage;

function safely<T>(fn: () => T, fallback: T): T {
  try {
    return fn();
  } catch {
    return fallback;
  }
}

export function readLastEra(getStore: GetStore = local): string | null {
  return safely(() => getStore().getItem(LAST_ERA_KEY), null);
}

export function writeLastEra(era: string, getStore: GetStore = local): void {
  safely(() => getStore().setItem(LAST_ERA_KEY, era), undefined);
}

/** Dismissed for this visit only, hence sessionStorage. */
export function readHidden(getStore: GetStore = session): boolean {
  return safely(() => getStore().getItem(HIDDEN_KEY) === "1", false);
}

export function writeHidden(hidden: boolean, getStore: GetStore = session): void {
  safely(() => {
    const store = getStore();
    if (hidden) store.setItem(HIDDEN_KEY, "1");
    else store.removeItem(HIDDEN_KEY);
  }, undefined);
}
```

```ts
  if (!layer || !petEl || !sprite || !dismiss) return;

  const coarseQuery = matchMedia("(pointer: coarse)");
  const reducedQuery = matchMedia("(prefers-reduced-motion: reduce)");

  let pet: LoadedPet | null = null;
  let pending: LoadedPet | null = null;
  /** The pet the latest page asked for; stale loads compare against it. */
  let targetId: string | null = null;
  let state: PetState | null = null;
  let hidden = readHidden();
  let cursor: { x: number; y: number } | null = null;
  let clicked = false;
  let rafId = 0;
  let lastTs = 0;
  let shownUrl = "";

  function layout(): { size: number; stationary: boolean; surface: Surface } {
    const coarse = coarseQuery.matches;
    const size = (pet?.def.frameSize ?? 32) * (coarse ? 2 : 3);
    const width = window.innerWidth;
    const stationary = reducedQuery.matches || width < NARROW_PX;
    const maxX = width - EDGE_PX - size / 2;
    const fullMinX = EDGE_PX + size / 2;
    // Touch screens get a shorter walk: the right half of the window.
    const minX = stationary ? maxX : coarse ? Math.max(fullMinX, width / 2) : fullMinX;
    return { size, stationary, surface: { minX: Math.min(minX, maxX), maxX } };
  }

  function render(size: number): void {
    if (!pet || !state) return;
    const anim = resolveAnim(pet.available, animFor(state.mode));
    const count = pet.frames[anim] ?? 1;
    const fps = pet.def.fps?.[anim] ?? DEFAULT_FPS[anim];
    const frame = frameAt(state.modeMs, fps, count, loops(state.mode));
    const url = spriteUrl(pet.def, anim);
    if (url !== shownUrl) {
      sprite.style.backgroundImage = `url("${url}")`;
      shownUrl = url;
    }
    petEl.style.setProperty("--pet-size", `${size}px`);
    sprite.style.backgroundSize = `${count * size}px ${size}px`;
    sprite.style.backgroundPosition = `${-frame * size}px 0`;
    sprite.style.transform = state.facing < 0 ? "scaleX(-1)" : "";
    const { y, opacity } = hop(state.mode, state.timerMs, pet.cfg);
    petEl.style.transform = `translate(${state.x - size / 2}px, ${y}px)`;
    petEl.style.opacity = String(opacity);
    petEl.classList.toggle("is-reacting", state.mode === "react");
  }

  function tick(now: number): void {
    rafId = requestAnimationFrame(tick);
    // Cap the step so a long pause (background tab, slow frame) can't teleport the pet.
    const dt = Math.min(now - lastTs, 100);
    lastTs = now;
    if (!pet || !state) return;
    const { size, stationary, surface } = layout();
    const centreY = window.innerHeight - size / 2;
    const input = {
      cursor: cursor
        ? { dx: cursor.x - state.x, dist: Math.hypot(cursor.x - state.x, cursor.y - centreY) }
        : null,
      clicked,
      surface,
      stationary,
    };
    clicked = false;
    const prevMode = state.mode;
    state = step(state, input, dt, Math.random, pet.cfg);
    // The old pet finished hopping out: bring the new one in at the same spot.
    if (prevMode === "exit" && state.mode !== "exit" && pending) {
      pet = pending;
      pending = null;
      state = createPetState(state.x, pet.cfg);
    }
    render(size);
  }

  function startLoop(): void {
    if (rafId || hidden || !pet || document.visibilityState === "hidden") return;
    lastTs = performance.now();
    rafId = requestAnimationFrame(tick);
  }

  function stopLoop(): void {
    cancelAnimationFrame(rafId);
    rafId = 0;
  }

  function applyHidden(): void {
    layer!.hidden = hidden;
    document
      .querySelectorAll<HTMLButtonElement>("[data-pet-restore]")
      .forEach((button) => (button.hidden = !hidden));
    if (hidden) stopLoop();
    else startLoop();
  }

  async function switchTo(def: PetDef): Promise<void> {
    if (def.id === targetId) return;
    targetId = def.id;
    if (pet && def.id === pet.def.id) {
      pending = null; // came back before a queued swap happened
      return;
    }
    const loaded = await loadPet(def);
    if (targetId !== def.id) return; // a newer page asked for a different pet meanwhile
    if (!loaded) return; // art missing: keep the current pet (or none)
    if (!pet || !state) {
      pet = loaded;
      const { surface, stationary } = layout();
      const x = stationary
        ? surface.maxX
        : surface.minX + (surface.maxX - surface.minX) * Math.random();
      state = createPetState(x, pet.cfg);
      petEl!.hidden = false;
      startLoop();
      return;
    }
    pending = loaded;
    state = requestSwap(state, pet.cfg);
  }

  sprite.addEventListener("click", () => {
    clicked = true;
  });

  dismiss.addEventListener("click", () => {
    hidden = true;
    writeHidden(true);
    applyHidden();
  });

  document.addEventListener("click", (event) => {
    if (!(event.target instanceof Element) || !event.target.closest("[data-pet-restore]")) return;
    hidden = false;
    writeHidden(false);
    if (pet && state) state = createPetState(state.x, pet.cfg);
    applyHidden();
  });

  document.addEventListener("pointermove", (event) => {
    if (event.pointerType === "mouse" || event.pointerType === "pen") {
      cursor = { x: event.clientX, y: event.clientY };
    }
  });
  document.documentElement.addEventListener("pointerleave", () => {
    cursor = null;
  });

  document.addEventListener("visibilitychange", () => {
    if (document.visibilityState === "hidden") stopLoop();
    else startLoop();
  });

  // Fires on the first load and after every ClientRouter navigation. The pet
  // element itself is persisted, so only the era (and the footer) change.
  document.addEventListener("astro:page-load", () => {
    const era = readPageEra();
    if (era) writeLastEra(era);
    applyHidden();
    void switchTo(choosePet(era, readLastEra()));
  });
}
```

Note: `choosePet(era, readLastEra())` is still right when storage is blocked. `readLastEra()` returns `null`, and an era page still gets its own pet from `era`.
